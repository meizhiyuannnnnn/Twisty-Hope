# 测试 Agent — 可用 Skills

## browser-use
- **用途**：浏览器端 E2E 自动化测试
- **使用时机**：需要模拟用户在浏览器中的真实操作流程时
- **效果**：导航、点击、输入、截图、数据提取全流程自动化

## web-perf
- **用途**：前端性能测试
- **使用时机**：验证页面是否满足性能指标要求时
- **效果**：Core Web Vitals 测量、渲染阻塞分析、缓存策略检查

## remote-browser
- **用途**：CI/CD 环境中的无头浏览器测试
- **使用时机**：需要在 GitHub Actions 等 CI 环境中运行浏览器测试时
- **效果**：沙箱化远程浏览器，适合自动化流水线
