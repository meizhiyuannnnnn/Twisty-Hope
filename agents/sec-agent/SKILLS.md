# 安全审查 Agent — 可用 Skills

## security
- **用途**：绘制安全架构图
- **使用时机**：需要可视化展示安全方案（IAM 流、加密管道、零信任架构）时
- **效果**：PlantUML 安全架构图，含身份/IAM、加密/KMS、网络防火墙、威胁检测图标

## sandbox-sdk
- **用途**：代码执行安全沙箱
- **使用时机**：审查需要执行用户代码的功能、构建安全执行环境时
- **效果**：隔离沙箱、代码解释器、文件系统安全

## web-design-guidelines
- **用途**：前端安全审查辅助
- **使用时机**：检查 CSP、XSS 防护、安全头配置时
- **效果**：Vercel 设计规范中包含部分安全检查项
