# 后端开发 Agent — 可用 Skills

## supabase-postgres-best-practices
- **用途**：PostgreSQL 性能优化最佳实践
- **使用时机**：设计 Schema、优化慢查询、配置连接池时
- **效果**：8 大类优化建议（索引、连接、RLS、Schema、并发、访问模式等）

## data-analytics
- **用途**：数据管道和分析架构图
- **使用时机**：设计数据 ETL、报表系统、数据仓库时
- **效果**：PlantUML 绘制的数据架构图，含 AWS 分析服务图标

## vega
- **用途**：数据驱动的统计图表
- **使用时机**：需要为后台管理系统生成数据可视化图表时
- **效果**：Vega-Lite 声明式图表（柱状、折线、散点、热力图等）
