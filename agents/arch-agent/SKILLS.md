# 架构设计 Agent — 可用 Skills

## architecture
- **用途**：绘制分层系统架构图
- **使用时机**：每个项目的核心产出——整体架构设计
- **效果**：12 种视觉风格 + 12 种布局模式，适合技术栈、微服务拓扑

## uml
- **用途**：绘制 UML 图（类图、时序图、组件图、部署图）
- **使用时机**：详细设计阶段，需要精确描述类关系或 API 调用时序时
- **效果**：14 种 UML 图类型，PlantUML 语法，9500+ 图标

## archimate
- **用途**：企业级架构全景图（TOGAF 标准）
- **使用时机**：大项目需要展现业务层→应用层→技术层全貌时
- **效果**：ArchiMate 标准，覆盖业务/应用/技术/动机/战略层

## graphviz
- **用途**：模块依赖关系图
- **使用时机**：分析包依赖、调用链、数据流向时
- **效果**：自动布局的有向图

## cloud
- **用途**：云部署拓扑图
- **使用时机**：涉及云服务部署的架构设计时
- **效果**：AWS/Azure/GCP/K8s 官方图标
