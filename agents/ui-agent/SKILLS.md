# UI/UX Agent — 可用 Skills

## frontend-design
- **用途**：设计独特视觉风格和界面
- **使用时机**：每个新项目/页面改版的设计阶段
- **效果**：创意配色、独特排版、动效方案、区别于「AI 风格」

## web-design-guidelines
- **用途**：Vercel 网页设计规范审查
- **使用时机**：设计交付前自查、前端实现后的设计走查
- **效果**：可访问性、设计一致性检查清单

## infocard
- **用途**：设计系统组件卡片展示
- **使用时机**：定义组件库、输出设计规范文档时
- **效果**：30+ 视觉风格，杂志级排版

## infographic
- **用途**：设计方案对比图、设计决策说明
- **使用时机**：向李振远汇报多个设计方案时
- **效果**：A vs B 对比、功能网格、路线图等 60+ 模板

## canvas
- **用途**：页面布局空间规划
- **使用时机**：设计初期，自由摆放页面元素规划布局
- **效果**：JSON Canvas 格式，精确定位节点
