# 需求分析 Agent — 可用 Skills

## brainstorming
- **用途**：与用户/李振远进行结构化需求访谈
- **使用时机**：需求不清晰、用户自己也不确定要什么时
- **效果**：逐轮提问厘清真实需求，避免「做了没人用」

## mindmap
- **用途**：需求拆解为可视化脑图
- **使用时机**：大需求拆分、功能树梳理时
- **效果**：层次化展示功能模块关系

## bpmn
- **用途**：绘制业务流程图
- **使用时机**：描述用户操作流程、审批流、订单状态流转时
- **效果**：BPMN 标准流程图，含泳道、网关、事件

## infographic
- **用途**：生成需求优先级矩阵、功能对比图
- **使用时机**：向李振远汇报需求排序、做竞品功能对比时
- **效果**：直观的信息图（SWOT、矩阵、对比表等）
