# DevOps Agent — 可用 Skills

## cloud
- **用途**：云部署架构图
- **使用时机**：部署方案设计、向团队展示基础设施拓扑时
- **效果**：AWS/Azure/GCP/K8s 9500+ 官方图标

## cloudflare
- **用途**：Cloudflare 全平台参考（Workers/D1/R2/Queues/AI 等）
- **使用时机**：选用 Cloudflare 作为部署平台时——决策树路由到正确产品
- **效果**：覆盖计算、存储、AI、网络、安全全产品线

## wrangler
- **用途**：Cloudflare Workers CLI 完整参考
- **使用时机**：实际执行 Cloudflare 部署、配置管理时
- **效果**：项目初始化→本地开发→部署→Secrets/资源管理

## agent-platform-deploy
- **用途**：将 AI 模型部署为在线推理服务
- **使用时机**：AI 项目需要部署模型端点时
- **效果**：模型发现→部署配置→成本估算→状态轮询→验证

## sandbox-sdk
- **用途**：构建安全代码执行沙箱
- **使用时机**：需要隔离执行用户代码、构建代码解释器时
- **效果**：沙箱生命周期管理、文件操作、端口暴露
