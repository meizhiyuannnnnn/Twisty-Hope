# 文档 Agent — 可用 Skills

## pdf
- **用途**：PDF 全功能处理（读/写/合并/拆分/加密/OCR）
- **使用时机**：需要处理 PDF 格式的文档时
- **效果**：提取文本/表格、创建 PDF、填表、水印、加密

## pdf-converter
- **用途**：高质量文档格式转换（MinerU API）
- **使用时机**：PDF/Word/PPT→Markdown/HTML 转换时
- **效果**：支持 80+ 语言、OCR、数学公式、表格还原

## infocard
- **用途**：知识卡片、KPI 仪表盘
- **使用时机**：制作项目总结、里程碑快报时
- **效果**：杂志级排版，30+ 视觉风格，40+ 布局骨架

## infographic
- **用途**：项目路线图、发布说明信息图
- **使用时机**：版本发布、项目汇报时
- **效果**：时间线、路线图、功能网格等 60+ 模板

## mindmap
- **用途**：文档结构规划脑图
- **使用时机**：规划大型文档结构时
- **效果**：层次化文档大纲可视化
