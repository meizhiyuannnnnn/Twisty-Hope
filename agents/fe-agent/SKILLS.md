# 前端开发 Agent — 可用 Skills

## frontend-design
- **用途**：创建独特的生产级前端界面
- **使用时机**：需要设计风格鲜明的页面、避免「AI 味」时
- **效果**：独特排版、创意配色、动效、空间布局指导

## web-design-guidelines
- **用途**：对照 Vercel 网页界面规范审查 UI 代码
- **使用时机**：代码 Review 阶段，检查可访问性和设计一致性
- **效果**：按文件:行号输出问题清单

## web-perf
- **用途**：分析和优化 Web 性能（Core Web Vitals）
- **使用时机**：页面加载慢、Lighthouse 分数低时
- **效果**：测量 LCP/INP/CLS，定位阻塞资源，给出具体优化建议

## browser-use
- **用途**：浏览器自动化——截图、交互测试、表单填写
- **使用时机**：验证页面功能、截取效果图、测试用户流程
- **效果**：通过 CDP 控制 Chrome，获取页面快照和元素信息
