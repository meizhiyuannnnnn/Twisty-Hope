# Claude 协调者 — 可用 Skills

> 这些是 Claude 在日常协调工作中可调用的专业技能。使用 `Skill` 工具调用。

## brainstorming
- **用途**：与李振远进行结构化方案探讨
- **使用时机**：启动新项目、遇到设计分歧、需要权衡技术方案时
- **效果**：通过逐轮提问厘清需求，给出 2-3 个带利弊分析的方案

## mindmap
- **用途**：项目任务分解、会议纪要可视化
- **使用时机**：项目启动时拆解 WBS、向李振远汇报项目结构时
- **效果**：生成层次化脑图

## architecture
- **用途**：评审 arch-agent 产出的架构图，或快速画架构草图
- **使用时机**：审查架构方案、向李振远解释技术架构时
- **效果**：生成分层架构图（12 种风格可选）

## find-skills
- **用途**：发现和安装新的 Agent skill
- **使用时机**：Agent 能力不足需要扩展时
- **效果**：从 skills.sh 搜索和安装社区 skill

## quality-gate
- **用途**：一键运行全部代码质量检查
- **使用时机**：功能开发完成、Review 前、终审前
- **效果**：生成统一质量报告（lint + typecheck + test）

## project-init
- **用途**：从模板初始化新项目
- **使用时机**：新项目立项后
- **效果**：一键创建目录结构 + 安装依赖 + 注册看板

## env-check
- **用途**：开发环境版本检查
- **使用时机**：项目初始化前
- **效果**：检查 Node/Python/Docker/Git 版本是否符合公司标准

## infocard
- **用途**：杂志级排版信息卡（HTML/CSS 嵌入 Markdown）
- **使用时机**：向李振远汇报项目状态、制作里程碑快报、Agent 产出摘要时
- **效果**：30+ 视觉风格 × 40+ 布局骨架，自动匹配内容密度和情绪调性

## infographic
- **用途**：模板化信息图（路线图、时间轴、KPI 仪表盘等）
- **使用时机**：项目进度可视化、版本发布说明、团队汇报时
- **效果**：60+ 模板，覆盖时间线/矩阵/漏斗/组织架构/图表等场景
