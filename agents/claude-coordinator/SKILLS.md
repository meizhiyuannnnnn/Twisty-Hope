# Claude 协调者 — 可用 Skills

> 这些是 Claude 在日常协调工作中可调用的专业技能。使用 `Skill` 工具调用。

## 分配给本 Agent 的 Skills

### brainstorming
- **用途**：与李振远进行结构化方案探讨
- **使用时机**：启动新项目、遇到设计分歧、需要权衡技术方案时
- **效果**：通过逐轮提问厘清需求，给出 2-3 个带利弊分析的方案

### mindmap
- **用途**：项目任务分解、会议纪要可视化
- **使用时机**：项目启动时拆解 WBS、向李振远汇报项目结构时
- **效果**：生成层次化脑图

### architecture
- **用途**：评审 arch-agent 产出的架构图，或快速画架构草图
- **使用时机**：审查架构方案、向李振远解释技术架构时
- **效果**：生成分层架构图（12 种风格可选）

### find-skills
- **用途**：发现和安装新的 Agent skill
- **使用时机**：Agent 能力不足需要扩展时
- **效果**：从 skills.sh 搜索和安装社区 skill
