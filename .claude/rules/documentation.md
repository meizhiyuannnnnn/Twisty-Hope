# 文档编写规范

## 语言
- 公司内部文档使用中文
- 代码/API 文档中英双语（中文描述 + 英文命名）

## 格式规范
- 标题层级：`#`（仅一个）→ `##` → `###`
- 数据优先用表格结构化
- 代码块标注语言：```python
- 列表层级不超过 3 层

## README.md 标准结构
```markdown
# [项目名称]
[一句话描述]

## 功能特性
## 快速开始
## 技术栈
## 项目结构
## 文档索引
```

## CHANGELOG.md 标准结构
```markdown
# Changelog
## [vX.Y.Z] — YYYY-MM-DD
### Added
### Changed
### Fixed
### Security
```

## 质量要求
- 可读性：目标读者能看懂
- 可操作：教程每一步都能跟着做
- 可维护：结构清晰，后续更新方便
- 及时更新：代码变更 → 文档同步

## 禁止
- 不用"好的"、"明白了"、"让我来..."等引导开头
- 不复述问题
- 不在末尾重复摘要
