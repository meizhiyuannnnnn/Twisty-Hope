## 二、Phase 9：视觉打磨（3-4 个 session，恢复开发后的起点）

**目标**：提升视觉品质，增加沉浸感

### 9.1 角色动画
- [ ] 角色像素动画（走路、工作、战斗）
- [ ] 车厢内角色可视化（显示角色在车厢内工作）
- [ ] 角色表情/状态动画（饥饿、受伤、开心）

### 9.2 车厢动画
- [ ] 车厢机械动画（轮子转动、蒸汽喷发）
- [ ] 车厢特效（厨房烟雾、医疗室灯光、武器舱炮管）
- [ ] 车厢损坏视觉（破损、冒烟、起火）

### 9.3 环境动画
- [ ] 动态日夜循环（天色随时间变化）
- [ ] 环境动画（树木摇摆、水面波纹）
- [ ] 天气效果升级（暴风雪、冰雹、雾）

### 9.4 光影效果
- [ ] 车厢内光源（窗户透光、灯光效果）
- [ ] 环境光遮蔽（阴影层次）
- [ ] 动态光源（火把、车灯、月光）

### 9.5 粒子效果
- [ ] 粒子效果升级（雪、烟、火、蒸汽）
- [ ] 环境粒子（树叶、灰尘、萤火虫）
- [ ] 交互粒子（脚步声扬起灰尘）

### 验收标准
- 角色有动画，不是静态图
- 车厢有机械动画和特效
- 有日夜循环
- 光影效果提升沉浸感

## 三、Phase 10：平衡与细节（2-3 个 session）

**目标**：打磨游戏体验，修复问题

### 10.1 数值平衡
- [ ] 资源消耗曲线（前中后期）
- [ ] 事件难度梯度
- [ ] 角色能力数值
- [ ] 车厢升级成本/收益
- [ ] 难度曲线（简单、普通、困难）

### 10.2 细节打磨
- [ ] 音效反馈（所有交互有音效）
- [ ] 视觉反馈（按钮悬停、点击效果）
- [ ] 过渡动画（场景切换、面板展开）
- [ ] 提示信息（教程、帮助、快捷键）

### 10.3 技术债（2026-11-24 收尾时发现）
- [ ] `event_bus.gd` 43 个信号被引擎报「声明但未显式使用」（编译警告噪音）
- [ ] 未使用参数/变量 3 处（`character_system.gd:576`、`character_panel.gd:547`、`event_dialog.gd:327`）
- [ ] 数据文件路径不统一（`data/train/` 与 `scripts/data/`）
- [ ] 启动日志因编译缓存重复输出

### 验收标准
- 数值平衡，难度曲线合理
- 所有交互有反馈
- 无严重 Bug
- 性能稳定

## 五、执行原则

1. **按顺序执行**：Phase 9 → 10 → 11
2. **每个 Phase 的工作流**：
   - 李振远玩游戏，记录问题/想法
   - 告诉 Claude 本次目标
   - Claude 拆解任务，分配 Agent（见 `.claude/docs/game-active-workflow.md`）
   - 实现 → Review → 验证 → commit
